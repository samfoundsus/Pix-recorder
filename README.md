# Pixel Recorder

A clean and modern Android voice recorder inspired by the Pixel Recorder experience.

## Features

- 🎙️ High-quality voice recording
- ▶️ Audio playback with speed control
- 🔍 Search recordings
- 🏷️ Categories & favorites
- ✏️ Rename and delete recordings
- 📤 Share audio & transcripts
- 💾 Custom storage location
- 📝 On-device transcription support
- 🎨 Material You Dynamic Color
- 🌙 Light & Dark mode
- ⚡ Smooth and responsive UI

## Requirements

- Android 12 (API 31) or newer
- Microphone permission
- Storage access for saving recordings

## Tech Stack

- Kotlin
- Jetpack Compose
- Material 3
- AndroidX
- Kotlin Coroutines
